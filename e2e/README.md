# اختبارات الداشبورد في المتصفح (Playwright)

بتفتح **كل شاشة** في الداشبورد، بحساب الأدمن وبحساب المورد، على مقاسين: كمبيوتر (1366) وموبايل (390). وبتفحص في كل شاشة:

- إنها فضلت على عنوانها، ومارجعتش لصفحة الدخول أو لصفحة "مش موجودة".
- مافيش خطأ JavaScript، ولا رد من الـ API بـ 500 أو أكتر.
- مافيش صورة مكسورة.
- مافيش مفتاح ترجمة ظاهر زي `APP.xxx` أو `WEB.xxx`.
- على الموبايل: الصفحة مابتتحركش بالعرض (مافيش Scroll جانبي).

وبتاخد **صورة كاملة لكل شاشة** في `test-results/screens/`، عشان حد يراجع الشكل بعينه.

الشاشات بتتقري من ملفات الـ Routes نفسها (`staff.routes.ts` و`app-routing.module.ts`)، فأي شاشة جديدة بتتختبر لوحدها. وكمان صفحات التفاصيل (حجز، وعميل، ومورد، وطلب خاص، وإيميل، ورحلة، وخروجة) بتتفتح على أول صف في القايمة بتاعتها.

## التشغيل

الفولدر ده ليه `package.json` منفصل، عشان مايلمسش مكتبات الداشبورد. وبيستخدم Chrome المتسطب على الجهاز، فمش بينزّل أي متصفح.

```bat
cd e2e
npm install
set DASHBOARD_URL=http://localhost:4200
set DASHBOARD_API_URL=http://localhost:5022/api/
set DASHBOARD_ADMIN_USER=...
set DASHBOARD_ADMIN_PASSWORD=...
set DASHBOARD_VENDOR_USER=...
set DASHBOARD_VENDOR_PASSWORD=...
npx playwright test
npx playwright show-report report
```

- **الوقت:** حوالي 25 دقيقة لكل مقاس (142 شاشة). ولتشغيل مقاس واحد: `--project=desktop` أو `--project=phone`.
- **الحسابات:** لو حساب مش متحدد، الشاشات بتاعته بتتخطّى.
- **الباسوردات** من متغيرات البيئة بس. والجلسة بتتحفظ في `.auth/`، وده متجاهَل في git.
- **الاختبارات بتقرا بس، ومابتحفظش أي فورم.** بس تسجيل الدخول بيكتب Refresh token، فشغّلها على Staging أو نسخة محلية.
